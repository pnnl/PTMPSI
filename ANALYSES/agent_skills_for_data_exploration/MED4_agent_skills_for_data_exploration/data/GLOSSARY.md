# Redox Proteomics Glossary

| Term | Plain English |
|------|--------------|
| PTM | Post-translational modification — a chemical change to a protein after it's made |
| Ox (Oxidation) | A redox modification on cysteine residues; indicates oxidative stress or signaling |
| Ac (Acetylation) | An acetyl group added to lysine residues; regulates protein function |
| Diel cycle | The 24-hour light/dark cycle organisms experience |
| Dawn perturbation | Cells kept in dark are suddenly exposed to light at 6:00 AM |
| Dusk perturbation | Cells in light are suddenly put in dark at 6:00 PM |
| Abundance-corrected | PTM levels adjusted for how much total protein is present |
| Site (e.g. G6PDH@C35) | A specific residue on a specific protein — G6PDH protein, cysteine #35 |
| Fold change (A/B) | How much higher/lower condition A is compared to B |
| adj-p | P-value corrected for multiple testing (Benjamini-Hochberg) |
| missing_check | Number of conditions where >50% of replicates have missing data — use for filtering |
| Spectral intensity | The measured signal for each protein/PTM in each sample |
