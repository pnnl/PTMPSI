# NW-BRaVE MED4 Proteomics Explorer

Interactive exploration of *Prochlorococcus* MED4 redox and acetylation
proteomics across diel light/dark perturbations - using a coding agent (VS Code + Copilot).

This was used to help domain experts quickly explore and analyze proteomics data, as well as triage for downstream analysis. 

Disclaimer: the AI can make mistakes!

## Prerequisites

- [VS Code](https://code.visualstudio.com/) with
  [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)
- [uv](https://docs.astral.sh/uv/) — fast Python package manager

## Setup

```bash
# Install uv (skip if you already have it)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Change directory and sync requirements
cd MED4_agent_skills_for_data_exploration
uv sync
``` 

In VS Code, open the `MED4_agent_skills_for_data_exploration` project and create a new copilot chat in `agent mode`. Then use the chat interface to ask questions and have the agent plan and execute coding tasks.

## Overview

- `/.github` contains copilot-instructions to orient the agent and skills for data analysis (see the individual skill READMEs for more details).
- `/data` contains example processed MED4 proteomics data, a glossary of domain specific terms (for non-experts), and gene annotations.
- `/outputs` contains `/artifacts`, `/intermediate` and `/logs` generated by the agent from an example prompt. Also includes the example `2026-07-23-example-chat-trace.json` agent trace.
- `/tmp` contains temporary scripts and data generated by the agent.
