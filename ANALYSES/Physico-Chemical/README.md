## Description ##
This analysis computes the physico-chemical changes between two HMM-aligned sequences, and plots a bar plot of the magnitude of changes for each sequence position. 

## Usage ##
In the ```/Scripts``` sub-directory do:
```python physchem_alignment_plot.py```

## Data Input Structure ##
-Physico-Chemical \
|__Scripts \
 |--- physchem_alignment_plot.py \
|__Data \
 |--- alignment FASTA \
